# X 互关检测 · 蓝V取关助手

一个 Chrome / Edge 浏览器插件：找出**曾经和你互关、后来取关了你**的 X（Twitter）账号，尤其是蓝V，集中列出来，可以一键或批量取关。

> [!WARNING]
> **使用前请先读完下面的「风险提醒」。** 短时间内大量取关违反 X 的使用规则，可能导致账号被限制、锁定，严重时会被封号。

---

## ⚠️ 风险提醒（必读）

X 的规则禁止短时间内大量、机械地关注或取关（官方叫 *aggressive following / follow churn*）。X 判断的是**行为本身**，不看你用什么工具：手动一下取关几百个，同样会被风控。

**取关建议：**

| 建议 | 说明 |
|---|---|
| **每天不超过 50–100 个** | 几百个的量，分几天慢慢清 |
| **不要一次全选取关** | 批量取关时只勾选一部分，分批进行 |
| **保持间隔** | 插件默认每个间隔 3–7 秒，**不要调小**；想更稳妥可以调大到 8–15 秒（见下方「配置」） |
| **不要同时大量关注别人** | 一边猛关注一边猛取关，正是 X 重点打击的涨粉行为 |
| **新号、刚被限制过的号更要保守** | 这类账号的风控阈值更低 |
| **出现异常立即停** | 出现限流提示、连续失败、需要验证手机号等情况，停下来，隔天再继续 |

**可能的后果（从轻到重）：** 关注/取关功能临时受限 → 账号临时锁定，要求验证手机号或完成人机验证 → 反复违规时可能被封号。

**扫描本身风险很低**：扫描只是读取你自己的关注列表，跟你在网页上翻看关注列表差不多。每扫一次大约发几十次请求，远低于 X 的接口限制。

> 本插件是个人工具，与 X Corp. 无关。使用插件产生的任何账号后果由使用者自行承担。X 没有公布取关的具体上限，上面的数字只是保守的经验建议，**不能保证安全**。

## 功能

- **取关了我**：曾经互关、后来取关了你的账号，附带发现时间
- **未回关**：你关注了、但目前没有关注你的所有账号（包括从来没回关的）
- 默认只显示蓝V，可切换查看全部；支持搜索、按粉丝数排序
- 单个取关 / 勾选后批量取关，随时可以停止
- 「忽略」：不想取关的账号可以隐藏，以后不再显示
- 导出 CSV
- 扫描结果保存在本机，关掉浏览器也还在，打开面板就能看，不用每次重扫
- 工具栏图标一键开启 / 关闭，关闭时页面上不显示任何东西

## 安装

支持 Chrome、Edge、Brave 等 Chromium 内核浏览器。

1. 下载本项目（GitHub 页面右上角 **Code → Download ZIP**），解压
2. 按你的系统运行安装助手，然后跟着窗口里的提示操作：
   - **Windows**：双击 `安装-Windows.bat`
   - **Mac**：双击 `安装-Mac.command`。提示无法打开时，右键 → 打开 → 打开；如果提示「没有权限」，打开「终端」，输入 `bash `（bash 后面有一个空格），把 `安装-Mac.command` 拖进终端窗口，回车
   - **Linux**：终端运行 `bash 安装-Linux.sh`
3. 安装助手会打开浏览器的扩展管理页。打开「开发者模式」，再把 `x-mutual-checker` 文件夹拖进去
4. 点浏览器右上角的拼图图标，把「X 互关检测」固定到工具栏

也可以手动安装：打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择 `x-mutual-checker` 文件夹。

> 安装后**不要删除或移动这个文件夹**，浏览器每次启动都会从这里读取插件。
>
> Chrome 不允许双击安装应用商店以外的插件，所以需要用开发者模式加载。启动时如果提示「停用开发者模式扩展程序」，点关闭即可。

## 使用

1. 打开 x.com 并登录，点工具栏上的插件图标开启（图标显示「开」）
2. 点右下角的浮窗按钮打开面板 →「开始扫描」
3. **第一次扫描**会记下当前和你互关的人作为基线，以后再扫描，才会在「取关了我」里列出新取关你的人。「未回关」第一次扫描后就能看
4. 勾选要取关的账号 →「取关选中」，或在单个账号上点「取关」

**浮窗按钮：**

- 可以按住上下拖动，松开后会记住位置
- 红色数字角标：取关了你的人数
- 扫描时外圈显示进度

**扫描速度：** 直接读取 X 的关注列表接口，每页 50 人。实测 2355 个关注约 22 秒读完，在后台标签页也能正常扫描。

## 配置

批量取关的间隔在 `x-mutual-checker/content.js` 顶部：

```js
const DELAY_MIN = 3000; // 毫秒
const DELAY_MAX = 7000;
```

改完后在 `chrome://extensions` 点插件卡片上的刷新 ↻，再刷新 x.com。

## 更新

用新文件覆盖原来的 `x-mutual-checker` 文件夹，然后在 `chrome://extensions` 点插件卡片上的刷新 ↻，再刷新 x.com。

## 隐私

- 所有数据（扫描结果、忽略列表、设置）只保存在你自己浏览器的本地存储（`chrome.storage.local`）里，按 X 账号分开存放
- 插件不会把任何数据发到 X 以外的地方，也没有自己的服务器
- 插件只在 x.com / twitter.com 上运行，权限只有 `storage`

## 工作原理

| 文件 | 作用 |
|---|---|
| `inject.js` | 运行在页面环境：从 X 网页版代码里自动找到关注列表接口的编号，带着你的登录状态分页读取关注列表；读取每个账号的蓝V标记、是否关注了你、粉丝数；调用取关接口 |
| `content.js` | 面板界面、浮窗、历史记录对比（找出取关了你的人）、批量取关 |
| `background.js` | 工具栏开关；接口取关失败时，在后台标签页打开对方主页自动点「取消关注」 |
| `content.css` | 样式，跟随 X 的浅色 / 深色主题 |

如果 X 改版导致读取失败，插件会在扫描结果里显示原因（例如 `快速模式不可用：HTTP 404`），并自动改用在关注页滚动读取的方式。

## 常见问题

**第一次扫描后「取关了我」是空的？**
正常。X 不会告诉你谁"以前"关注过你。插件要先记下一份互关名单，下次扫描时再对比。

**为什么每次都要读完整个关注列表？**
取关你的人可能在列表的任何位置，只有把每个人当前的状态重新看一遍才能找出来。好在一次只要几十秒，建议隔几天扫一次。

**面板提示「看不出谁关注了你」？**
说明 X 改了数据格式，这次结果不会保存，避免把所有人误判成未回关。请提 Issue。
